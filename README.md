## 📄 Abstract
This repository contains the Python analysis code and CSV datasets used to reproduce the numerical results reported in the manuscript *“Stage-resolved malaria detection using a fingerprint-guided dual-band metamaterial optical biosensor.”* The provided tools enable post-processing of wavelength-dependent absorption data to extract key sensing metrics, including resonance shifts, sensitivity, quality factor (Q), and figure of merit (FOM). The analysis framework operates entirely on exported numerical data and does not require access to commercial electromagnetic simulation software.

---

## 🧪 Repository Contents
- Python notebook for data loading, spectral analysis, and visualization  
- CSV datasets for:
  - Healthy and malaria-infected red blood cell stages  
  - Incident-angle analysis under TE and TM polarization  
  - Surface roughness effects  
  - Optimization training data  

All results reported in the manuscript can be reproduced using the materials provided here.
